# Responsive sign-up form for UKM ITS 2024 (Web Programming assignment week 4 to create a registration form)

## 📌 About
This project is a responsive sign-up form designed for UKM ITS 2024, featuring a clean UI with multiple input fields for user registration

## ✨ Features
- User-friendly Registration Form: Input fields for name, email, password, gender, and phone number
- Form Validation: Ensures secure password input with specific requirements
- Custom UI Elements: Styled with CSS for a modern look

## 🛠 Technologies Used
- HTML5 for structure
- CSS3 for styling (global styles and custom UI)
- JavaScript (optional for enhancements)
